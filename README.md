# Personal Portfolio (2023)

A single-page portfolio site built with Next.js and styled-components —
introduction, project list, technologies, timeline and accomplishments.

## Sections

Hero · Projects · Technologies · Accomplishments · Timeline · Footer

Content is kept in `src/constants/constants.js`, separate from the components
that render it. Each component sits beside its own styled-components file.

## Stack

Next.js · React · styled-components · React Icons

## Running locally

```bash
yarn install
yarn dev
```
